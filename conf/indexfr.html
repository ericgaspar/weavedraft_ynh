WeaveDraft

Calcule le motif obtenu pour un enlissage, attachage et un pédalage donnés.

JavaScript est nécessaire pour utiliser WeaveDraft. Veuillez activer JavaScript (ou désactiver les bloqueurs de scripts) pour ce site.

Instructions (Cliquez pour afficher)

Configuration

  • Réglez le nombre de fils (lisses) sur votre métier à tisser
  • Définir le nombre de cadres
  • Définir le nombre de pédales
  • Définissez le nombre de rangées de trame (si le motif se répète, il peut s'agir du nombre de rangées avant une répétition, ou de deux ou trois fois ce nombre, pour voir à quoi ressemblera le motif ).

Couleurs

  • Choisissez le nombre de fils de couleurs différentes que vous utiliserez (c'est-à-dire le nombre de échantillons de couleur)
  • Pour chaque échantillon, double-cliquez pour définir la couleur du fil. Cliquez sur le bouton « Personnalisé » pour sélectionner n'importe quelle couleur, puis utilisez la pipette pour choisir des couleurs à partir de photos, de pages Web, etc.
  • Pour chaque opération, cliquez une fois sur un échantillon pour définir la couleur actuelle (par exemple, la couleur de la chaîne)

Enlissage

  • Choisissez une couleur (cliquez sur l'échantillon), puis cliquez ou faites glisser pour la placer sur un lisse spécifique. Vous pouvez faire glisser pour attribuer la même couleur à plusieurs lisses.
  • Ctrl + clic permet de supprimer une case d'enlissage.

Attachage

  • Cliquez sur une case dans la zone de liaison pour indiquer que cet axe sera relevé lorsque la pédale correspondante sera enfoncée. Vous pouvez faire glisser le curseur pour sélectionner plusieurs cases.

Pédalage

  • Commencez par le bas (le tissage remonte vers le haut, en s'éloignant de vous, au fur et à mesure que vous tissez)
  • Choisissez une couleur (cliquez sur l'échantillon)
  • Cliquez sur une case du pédalage pour indiquer que vous appuierez sur cette pédale pour cette rangée
  • Vous pouvez cocher la case « Appuyer sur plusieurs pédales », ce qui vous permet d’en actionner plusieurs (par exemple, une avec chaque pied). Dans ce cas, cliquer sur une case du pédalage permet de l’activer ou de la désactiver. Si plusieurs pédales sont enfoncées, tous les axes reliés à toutes les pédales enfoncées seront relevés.
  • Ctrl+clic supprime une case de pédale ; seule la rangée du haut peut être vidée de sa dernière case.

Répéter l'enlissage ou le pédalage

  • Cliquez sur « Dupliquer le motif d'enlissage à droite » si votre motif (saisi à gauche) se répète : cela copiera le motif existant pour remplir toute la zone de trame.
  • Cliquez sur « Dupliquer le motif pédalage vers le haut » si votre motif se répète verticalement : cela copiera le motif existant vers le haut pour remplir toute la zone de trame.

Chargement et enregistrement

  • Le motif s'actualise au fur et à mesure que vous avancez, et votre travail est enregistré automatiquement dans ce navigateur .
  • Pour enregistrer un motif afin de le réutiliser plus tard, cliquez sur « Enregistrer ». Vous pourrez ensuite créer un nouveau motif ou envoyer le fichier enregistré à un ami.
  • Cliquez sur « Charger » pour réimporter un motif existant.
  • Cliquez sur « Nouveau » pour commencer avec un nouveau modèle par défaut.
  • Pour imprimer un modèle, faites une capture d'écran et imprimez-la.
