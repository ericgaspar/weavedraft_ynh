Instructions (Click to show)

Configuration

  • Set the number of threads (heddles) in your loom
  • Set the number of shafts
  • Set the number of pedals
  • Set the number of weft rows (if the pattern repeats, it could be the number of rows before a repeat, or two or three times that, to see what the pattern will look like).

Colours

  • Choose the number of different colour threads you will use (ie. number of colour swatches)
  • For each swatch double-click to set the thread colour. Click the Custom button to select any colour, and use the colour picker (eye dropper) to choose colours from photos, web pages, etc.
  • For each operation, single-click a swatch to set the current colour (eg. warp colour)

Threading

  • Pick a colour (click on the swatch) and then click or drag to place it on a particular heddle. You can drag to set multiple heddles to the same colour.
  • Ctrl+click removes a threading box.

Tie-up

  • Click on a box in the tie-up area to indicate that this shaft will be raised if the corresponding pedal is pushed. You can drag across to set multiple boxes.

Pedalling

  • Start at the bottom (the weave moves upwards, away from you, as you weave)
  • Pick a colour (click on the swatch)
  • Click on a pedal box to indicate that you will press this pedal for this row
  • You can check "Press multiple pedals" which lets you press more than one pedal (eg. one with each foot). In this case clicking on a pedal box toggles it on and off. If multiple pedals are pressed then all shafts connected to all pressed pedals will be raised.
  • Ctrl+click removes a pedal box; only the top row can be emptied of its last box.

Duplicating threading or pedalling

  • Click "Duplicate threading right" if your pattern (entered at the left) repeats - it will copy the existing pattern over to fill the entire threading area.
  • Click "Duplicate pedalling up" if your pattern repeats vertically - it will copy the existing pattern up to fill the entire weft area.

Loading and saving

  • The pattern updates as you go, and your work is saved in this browser automatically.
  • To save a pattern for later click "Save". Then you can make a new pattern or send the saved file to a friend.
  • Click "Load" to load an existing pattern back in.
  • Click "New" to start with a new default pattern.
  • To print a pattern take a screenshot and print that.
